Comment sont choisis les visuels FR ?
En mode « FR puis EN », un visuel français n'est utilisé que si le titre FR diffère du titre EN (ex. Le Seigneur des anneaux). Sinon (Dune, Inception…), le visuel anglais est préféré — identique, sans accroche française superflue.
La comparaison utilise le titre fr-FR, jamais le titre québécois (fr-CA), pour éviter les faux écarts du type « Sens dessus dessous » / Vice-Versa.
Les œuvres françaises d'origine conservent toujours leurs visuels FR : c'est leur langue native.
Limite connue : TMDB n'indique pas le pays des images elles-mêmes — un visuel québécois peut exceptionnellement passer. Le choix manuel (clic sur la case) permet toujours de corriger.
Quels formats d'images sont acceptés à l'import ?
JPEG, PNG, WebP, AVIF, GIF (première image) et BMP. Les HEIC (photos iPhone), TIFF et RAW ne sont pas décodables par le navigateur : ils sont ignorés proprement.
À l'import 📁 Dossier, les images sont recompressées en JPEG : un PNG transparent perd son fond. Le glisser-déposer individuel sur une case conserve, lui, le fichier tel quel.
Pourquoi l'import de dossier remplit-il depuis le centre ?
Les cases sont triées par distance au centre du wallpaper (inclinaison comprise) avec une part d'aléatoire : s'il y a moins d'images que de cases, le cœur du wallpaper est toujours garni en premier plutôt que de laisser des trous éparpillés.
Pourquoi ai-je des images en double ?
Quand la source (genres, saga, liste) contient moins de titres que la grille n'a de cases, les titres sont répétés pour tout remplir — en variant les visuels et en évitant deux fois le même titre côte à côte.
Pour réduire les répétitions : élargissez la source, réduisez le nombre de cases, ou fixez un plafond via l'option Répétitions.
« Pool épuisé » lors d'une regénération, que faire ?
Tous les titres de la source sont déjà affichés sur la grille. Élargissez la source (plus de genres, liste plus fournie) ou relancez un remplissage auto avec d'autres paramètres.
Mes sauvegardes .json sont-elles lourdes ?
Les visuels TMDB sont stockés en simples liens : quelques Ko. Les images locales (glisser-déposer, 📁 Dossier) sont incluses dans le fichier, recompressées à 1000px — un projet riche en images personnelles pèsera donc plus lourd, c'est normal.
Le brouillon automatique, comment ça marche ?
Le projet est enregistré toutes les 30 secondes dans le navigateur (IndexedDB) et proposé à la réouverture. Il est propre à ce navigateur et à cette machine : la sauvegarde .json reste le vrai fichier portable.
Pourquoi impossible d'échanger une affiche et un paysage ?
Leurs cadrages sont incompatibles (2:3 contre 16:9) : l'échange est limité au même type pour éviter des recadrages disgracieux.
Où sont stockées mes clés API ?
Uniquement dans le stockage local de votre navigateur (localStorage). Elles ne transitent que vers les API concernées : TMDB et Trakt — jamais ailleurs.
Pourquoi MDBList n'est-il pas disponible ?
L'API MDBList n'autorise pas les appels directs depuis un navigateur (pas de CORS) : il faut un proxy auto-hébergé. Cette fonctionnalité est donc réservée à la version locale de l'outil.
Le mode clair change-t-il le wallpaper exporté ?
Non : le thème n'affecte que l'interface. Le rendu du wallpaper et l'export PNG sont rigoureusement identiques dans les deux modes.
