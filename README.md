# Wallpaper Maker by JukeBoX

Générateur de fonds d'écran en mosaïque d'affiches/paysages de films et séries, en un seul fichier HTML, sans dépendance ni build. Recherche via l'API [TMDB](https://www.themoviedb.org/) et [Trakt](https://trakt.tv/), export en PNG haute résolution (jusqu'à 4K) via [html2canvas](https://html2canvas.hertzen.com/).

## Utilisation

Ouvrez [`index.html`](index.html) dans un navigateur, ou via GitHub Pages : https://VOTRE-USER.github.io/jukebox-wallpaper-maker/

Des clés API personnelles TMDB et Trakt sont requises (gratuites) et se configurent directement dans l'interface. Elles sont stockées uniquement dans le `localStorage` de votre navigateur, jamais transmises ailleurs.

## Fonctionnalités

- Remplissage automatique ou par dossier/sélection manuelle
- Mélange, styles de mosaïque
- Export PNG jusqu'en 4K
